BAB 16 — AUTONOMOUS ENGINE: MESIN OTONOM DI BALIK LAYAR
================================================================================

"Yang membuat Fusion Neural berbeda dari chatbot biasa adalah Autonomous
Engine — mesin otonom yang berjalan 24/7 di backend.

--- AUTONOMOUS LOOP ---

Backend menjalankan loop kontinu yang:

Phase 0: DLQ Sweeper
- Mendeteksi task yang macet lebih dari 10 menit (zombie tasks)
- Auto-retry hingga 3 kali
- Jika masih gagal, mark sebagai FAILED

Phase 1: Manager Review Loop
- Manager AI mereview semua task yang selesai
- Menyetujui atau mengembalikan untuk revisi
- Memastikan kualitas output sebelum sampai ke manusia

Phase 1.5: Automated Operations
- Stock Watchdog: Membuat task restock otomatis jika stok menipis
- Content Publisher: Auto-publish konten Instagram yang sudah dijadwalkan
- Budget Alert: Peringatan jika token budget hampir habis

Phase 2: Priority Queue Processing
- Mengambil task dari queue berdasarkan prioritas
- Mengunci task agar tidak diproses dua kali
- Mendispatch ke worker yang sesuai

Idle Mode:
- Ketika tidak ada task, AI melakukan financial audit terhadap
  transaksi-transaksi terakhir

--- SCHEDULER LOOP ---

Scheduler membaca collection 'agent_schedules' dan membuat task otomatis:
- Daily: Task yang harus dilakukan setiap hari
- Weekly: Task berdasarkan hari (Senin, Selasa, dll)
- Monthly: Task berdasarkan tanggal

--- WORKER PIPELINE ---

Setiap task melewati pipeline:
1. Budget Check — Pastikan token budget mencukupi
2. Memory Injection — AI mendapat konteks dari percakapan terakhir
3. AI Execution — Eksekusi dengan fallback chain (jika AI utama gagal,
   otomatis beralih ke backup)
4. Physical Action — Eksekusi tindakan nyata (kirim email, buat file,
   publish konten)
5. Transcript Logging — Semua percakapan dicatat untuk training
6. Review Queue — Task masuk ke review, bukan langsung Done

--- FALLBACK CHAIN (7 AI PROVIDERS) ---

Jika satu AI provider down, sistem otomatis beralih ke provider berikutnya:
Groq → DeepSeek → Mistral → Gemini → Cerebras → OpenRouter → Cohere

Ini memastikan uptime 99.9%."
